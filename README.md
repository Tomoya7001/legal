# legal

Privacy policies and support pages for Tom's Apps, served by GitHub Pages at https://tomoya7001.github.io/legal/

Add a new app: create `<app>/privacy.html` and `<app>/support.html` (copy `norige/` as a template, set `--brand` on `<body>`), then add a row to `index.html`.
Fusegi's existing pages stay at https://tomoya7001.github.io/fusegi-legal/ (linked from the index) because the released app points there.
